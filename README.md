# Word Memory 单词记忆法生成器

这是一个可以直接在浏览器中打开的英语学习工具。输入单词或词组后，页面会调用 DeepSeek API 生成中文记忆笔记，包括音标、常见含义、拆分联想、例句和常用搭配。觉得有用的内容可以收藏起来，之后按页面安排进行复习。

整个项目只有一个 HTML 文件，不需要安装 Node.js、数据库或其他运行环境。收藏内容和复习记录保存在当前浏览器中，适合个人在本地使用。

## 主要功能

- 单词和词组两种生成模式
- 自动整理音标、释义、记忆方法、例句和搭配
- 收藏生成结果，保留原始 Markdown 内容
- 根据复习反馈安排下一次复习时间
- 支持“忘记、模糊、记得、简单”四档反馈
- 按收藏时间或字母顺序查看词库
- 支持搜索、删除和重新加入复习
- 词库可以导出为 JSON，也可以在其他浏览器中合并导入

## 使用方法

1. 下载仓库中的 `word-memory.html`。
2. 双击文件，用 Chrome、Edge 等现代浏览器打开。
3. 在 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys) 创建 API Key，并填入页面。
4. 选择“单词速记”或“词组速记”，输入要学习的内容，点击“生成”。
5. 检查生成结果后，点击右上角星标加入收藏。
6. 侧栏出现待复习内容时，点击“开始复习”。

API 调用可能产生费用，具体价格以 DeepSeek 开放平台为准。页面默认不会长期保存 API Key；只有主动勾选“在此浏览器保存 Key”后才会写入浏览器存储。这里使用的 Base64 只是编码，不是加密，不建议在公共电脑上保存 Key。

## 复习状态

侧栏中每个词条前面都有一个彩色圆点：

- **新词**：已经收藏，但还没有复习过。
- **学习中**：已经复习过，距离下次复习不到 7 天。
- **待复习**：已经到了复习时间，会进入待复习列表。
- **已复习**：下次复习安排在 7 天以后。
- **已掌握**：当前复习间隔达到 21 天，不再自动进入复习列表。

如果想重新学习“已掌握”的内容，可以点击词条右侧的重新复习按钮。

## 在不同浏览器之间迁移词库

浏览器之间不会共享本地数据。例如，在 Edge 中收藏的词条不会自动出现在 Chrome 中。可以通过侧栏的两个按钮迁移：

1. 在原浏览器中点击“导出词库”，保存 JSON 文件。
2. 在目标浏览器中点击“合并导入”，选择刚才的 JSON 文件。

导入采用合并方式：只增加目标浏览器中没有的词条。遇到同名、同类型的内容时，会保留目标浏览器现有版本，避免覆盖已经积累的复习进度。导出文件只包含收藏和复习记录，不包含 API Key。

建议偶尔导出一次词库作为备份。清除浏览器网站数据或重装浏览器，可能会删除保存在本地的收藏。

## 数据与隐私

- 收藏、复习时间和 API Key 设置使用浏览器的 `localStorage` 保存。
- 单词和词组会发送给 DeepSeek API，用于生成记忆内容。
- 项目没有自己的服务器，也不会把词库上传到其他位置。
- 更换浏览器、浏览器用户或本地文件路径后，可能会得到一份独立的本地数据。
